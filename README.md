Launch Radar ranks every pre-token protocol in a DefiLlama snapshot by implied launch value — TVL times the FDV/TVL multiple its own category earned, adjusted for 7-day growth, age with no token, and chain breadth — and writes a dashboard with a concrete farm plan for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

Node 22 or later, standard library only, no network. The program reads the snapshot, writes
`out/board.json` (every pre-token candidate, ranked), `out/dashboard/` (the page and its data),
`out/screenshots/` (copied from this repository) and `out/dossier.json`, then checks its own
output against the gate and exits non-zero when a row fails. Run it twice: both runs write the
same bytes.

## How the value is computed

```
implied value = TVL × category multiple × growth × age × chains
```

- **Category multiple** — the median FDV/TVL of the launched protocols in the same category
  (global median when a category has fewer than three launched comps), clamped to 0.02–1.50.
- **Growth** — the 7-day TVL change, clamped to −50%…+100% and halved into a factor of 0.75–1.50.
- **Age** — years listed with no token, +4% a year, capped at +16%.
- **Chains** — +2% per chain it runs on, capped at +10%.

No protocol name is hardcoded: the calibration and the ranking are recomputed from whatever
snapshot the program reads, so a future snapshot prices future protocols. A protocol is a launch
candidate when DefiLlama records no token for it and it is not a wrapped, staked or bridged
product of a token that already trades — the same rule the snapshot's own watchlist uses.

## Layout

- `main.ts` — entrypoint: reads the snapshot, builds the board, writes the outputs, self-checks
- `lib/model.ts` — eligibility, calibration, scoring, ranking
- `lib/farm.js` — the farm-plan engine (shared by the program and the dashboard)
- `lib/gate.ts` — the gate as a self-check over the program's own output
- `dashboard/` — the page (`index.html`, `app.css`, `app.js`); `data.js` is generated by the program and `farm.js` is copied from `lib/`
- `screenshots/` — the board, a protocol's detail view, and a filtered view
